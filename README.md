# Skullgirls: Rough Cut

This project is a work in progress.

Single Player → Story Mode previews all 18 original story routes, including their
endings and post-credits scenes, using your local game assets. Space/Z advances
dialogue; Enter/Start skips a cutscene; Escape returns to the menu. Enemies use a
temporary idle AI, and special/boss encounters offer a continue checkpoint.
Story audio is not implemented yet.
